# Dinacharya Launcher brand

Logo C, "Timeline": three slots of a day and an amber now-line.

Colours: ground `#0B1F1D`, teal `#2DD4BF`, amber `#FBBF24`, cream `#EAF6F3` (faded slots at 28 %).

| File | Use |
|---|---|
| `play-icon-512.png` | Google Play app icon (512 × 512, no transparency) |
| `play-feature-graphic-1024x500.png` | Google Play feature graphic |
| `logo-square.svg` / `logo-rounded.svg` | Master logo, full square or rounded |
| `logo-1024.png` | Large rounded logo with transparent corners |
| `mark-transparent.svg` | The mark alone, for dark backgrounds |
| `mark-mono.svg` | One-colour mark |

In the app the icon is the adaptive icon in `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
(`drawable/ic_fg.xml` on `@color/icon_bg`, themed icon `drawable/ic_mono.xml`); notifications use
`drawable/ic_stat.xml`, the same mark in white.
